# ysuhan.dev

> 从想法到作品，从创意到体系 — Build Ideas Into Reality.

Personal brand website built with VitePress, featuring a digital garden, project showcase, technical blog, and portfolio.

## Tech Stack

- **Framework:** VitePress + Vue 3
- **Styling:** UnoCSS
- **Language:** TypeScript
- **Deployment:** GitHub Pages

## Getting Started

```bash
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # production build
pnpm preview  # preview build
```
